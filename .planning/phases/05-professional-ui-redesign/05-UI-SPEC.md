## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Button padding, list-row horizontal padding, card content padding |
| md | 16px | Inner card spacing, folder tree item gaps, list row spacing |
| lg | 24px | Grid gap, sidebar internal padding, details drawer padding |
| xl | 32px | Header-to-content gap, top bar padding, main layout margin |
| 2xl | 48px | Page margins, empty-state spacing |
| 3xl | 64px | Full-page overlay padding, vertical layout spacing |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f4f5` (Light) / `#09090b` (Dark) | App backdrop, background surfaces |
| Secondary (30%) | `#ffffff` (Light) / `#18181b` (Dark) | Sidebar panel, cards, top bar, details panel |
| Accent (10%) | `#5865F2` (Blurple) | Active nav item backgrounds, checkmarks, primary buttons |
| Destructive | `#ef4444` (Zinc/Red) | Delete button, warning text, revoke link |

Accent reserved for: Active sidebar link indicator, upload progress bar fill, lock indicator active states, checkbox focus indicator.
