# Plan 01-03: Download Stream Reassembly & CDN URL Refresh

Implement chunk download streaming, sequential reassembly, dynamic CDN url refresh on 403/404 expiry failures, and chunk message deletion from Discord.

## must_haves

- [ ] Route `POST /storage/download` accepting list of chunk descriptors and streaming back the reassembled file content
- [ ] Automated recovery when Discord CDN requests return 403/404 (re-fetch message metadata via webhook and retry download with new URL)
- [ ] Route `POST /storage/delete` accepting list of chunk descriptors and calling DELETE message webhook endpoint on Discord for each chunk
- [ ] Integration tests verifying download reassembly, 403 retry refresh mechanism, and delete route using mocked Discord endpoints
