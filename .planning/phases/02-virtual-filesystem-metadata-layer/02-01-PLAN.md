# Plan 02-01: SQLite Database Bootstrap & Schema

Initialize the SQLite database layer, define the schema for nodes and chunks, create a connection helper, and add Vitest coverage for schema initialization and basic CRUD primitives.

## Traceability

- **Decisions Covered:** D-01, D-02, D-03, D-04, D-11
- **Requirements Covered:** FS-01, FS-02 (foundation only)

## must_haves

- [ ] `better-sqlite3` integrated; default DB path `./data/wyvern.db`, overridable via `DB_PATH` env var
- [ ] Database file and parent directory created automatically on startup
- [ ] `nodes` and `chunks` tables created via `CREATE TABLE IF NOT EXISTS` with all required columns, indexes, and `ON DELETE CASCADE`
- [ ] `src/services/fs-repo.ts` exports typed repository functions for the foundation: `createNode`, `getNode`, `listChildren`, `renameNode`, `deleteNode` (single node only; cascade happens in Plan 02-02)
- [ ] All repository functions accept and filter by `accountId`
- [ ] Unit tests in `tests/fs-repo.test.ts` cover: schema init idempotency, create+list, rename, single-node delete

    Create src/db/schema.ts exporting a `SCHEMA_SQL` constant:
    - CREATE TABLE nodes (
        id TEXT PRIMARY KEY,
        parent_id TEXT REFERENCES nodes(id) ON DELETE CASCADE,
        account_id TEXT NOT NULL,
        name TEXT NOT NULL,
        kind TEXT NOT NULL CHECK (kind IN ('file','folder')),
        size_bytes INTEGER,
        mime_type TEXT,
        created_at INTEGER NOT NULL,
        updated_at INTEGER NOT NULL
      );
    - CREATE INDEX idx_nodes_account_parent ON nodes(account_id, parent_id);
    - CREATE UNIQUE INDEX idx_nodes_sibling ON nodes(account_id, parent_id, name COLLATE NOCASE);
    - CREATE TABLE chunks (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        node_id TEXT NOT NULL REFERENCES nodes(id) ON DELETE CASCADE,
        discord_message_id TEXT NOT NULL,
        "index" INTEGER NOT NULL,
        size_bytes INTEGER NOT NULL,
        cdn_url TEXT NOT NULL
      );
    - CREATE UNIQUE INDEX idx_chunks_order ON chunks(node_id, "index");
    Create src/db/database.ts:
    - Export function openDatabase(dbPath?: string): Database
    - Default dbPath = process.env.DB_PATH || path.join(process.cwd(), 'data', 'wyvern.db')
    - Ensure parent directory exists (fs.mkdirSync recursive)
    - PRAGMA journal_mode = WAL; PRAGMA foreign_keys = ON;
    - Run SCHEMA_SQL once at open
  </action>
