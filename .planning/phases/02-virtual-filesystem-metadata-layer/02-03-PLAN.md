# Plan 02-03: Backup Export & Restore (JSON)

Implement the JSON export/import of account metadata, gated by account_id match, executed as a single transaction.

## Traceability

- **Decisions Covered:** D-08, D-09, D-10, D-12
- **Requirements Covered:** FS-05

## must_haves

- [ ] `GET /fs/backup` returns a JSON document scoped to the requester's `account_id` with `version: 1`, `exported_at`, and arrays of `nodes` and `chunks`
- [ ] `POST /fs/restore` accepts the same JSON shape; validates `version === 1` and `account_id` match; replays nodes and chunks inside a single transaction; rejects 400 on schema mismatch
- [ ] Restore never writes rows for a different `account_id`
- [ ] Tests cover: export of an account only includes that account's data; restore inserts; restore rejects foreign account_id; restore is atomic on failure
