# Phase 0: Monorepo & Tooling Foundation

**Goal**: Working pnpm + turborepo monorepo with shared TS/lint/format config, root scripts, and CI skeleton.

**Depends on**: Nothing (first phase)
**Requirements**: (none — tooling only)
**Status**: Pending

## Context

This phase locks the monorepo shape that every later phase inherits. Done right, later phases can focus on their product work; done wrong, every later phase fights the toolchain.

**Key prior work to clean up first**:

1. The prior v2 attempt (Hono + Vite + Argon2) is staged for deletion in the git index. Commit those deletions as a single `chore: wipe v2 attempt` commit before adding new files.
2. The v1 reference (`extension/`, `server/`, `web/`) is untracked. Leave it in place for now — later phases can read from it. Add it to `.gitignore` so it doesn't get accidentally committed.

## Plan 00-01: Workspace skeleton, shared configs, CI, root scripts

**Tasks**:

1. **First-commit cleanup**: `git rm -r --cached <paths>` for all the prior v2 deletion-staged files. `git commit -m "chore: wipe v2 attempt"`.
2. **Root `package.json`**: name `disbox`, private, `packageManager: pnpm@9`, root scripts (`build`, `dev`, `lint`, `typecheck`, `test`, `clean`, `format`).
3. **`pnpm-workspace.yaml`**: declare `apps/*` and `packages/*`.
4. **`turbo.json`**: pipeline with `build`, `dev` (cache: false, persistent), `lint`, `typecheck`, `test`, `clean`. `build` depends on `^build`.
5. **`tsconfig.base.json`**: shared compiler options (strict, ES2022, Bundler resolution, `noUncheckedIndexedAccess`).
6. **`.gitignore`**: node*modules, .next, dist, build, .turbo, data, *.db, \_.sqlite, .env\*, coverage, IDE files.
7. **`.prettierrc.json`**: 2-space, single quotes, trailing commas, 100-col, LF.
8. **`AGENTS.md`**: workflow commands + project conventions + critical gotchas.
9. **Top-level `README.md`**: project description, structure, quick start, ToS warning.
10. **Package stubs**: `packages/shared`, `apps/web`, `apps/server`, `apps/ext` — each with `package.json` declaring `name`, `private: true`, and a `workspace:*` dep on `@disbox/shared` for the apps. Stub `src/index.ts` in shared. Stub `README.md` per package.
11. **CI skeleton** (`.github/workflows/ci.yml` if GitHub Actions; otherwise leave a note): install, lint, typecheck, build, test.

**Acceptance**:

- `pnpm install` succeeds in < 60 s on a clean clone.
- `pnpm -r typecheck` passes (with stub types).
- `pnpm -r lint` passes (or is no-op for stubs).
- `pnpm -r build` produces a `dist/` in `packages/shared`.
- All four workspace packages are listed by `pnpm -r list`.
