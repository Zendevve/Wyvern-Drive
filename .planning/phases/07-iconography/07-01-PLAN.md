<objective>
Replace every emoji-as-icon in the app with @phosphor-icons/react, establish a single icon map for file-type icons, and guarantee accessible names on icon-only buttons.

Purpose: The design skill section 9.D bans emoji-as-icon (zero tolerance). The audit found 30+ emoji characters currently used as icons across the app shell, audio player, drop zone, file list, folder tree, details drawer, share modal, lightbox, and password modal.

Output: A single source of truth for icons (icon-map.ts + direct Phosphor imports), zero emoji-as-icon rendered anywhere, and complete aria-label coverage on icon-only controls.

Scope guard: This phase does NOT add new features, does NOT touch theme tokens (Phase 06 owns that), does NOT touch motion, layout, viewport, fonts, or z-index. It does NOT add marketing-page iconography (no giant marketing hero icon, no animated icon-loop) — Phosphor is used only as functional UI control icons. No icon animation; Phosphor icons inherit the existing transition utilities of their parent button.
</objective>
