<objective>
Migrate five components off orphan Discord-purple classes (bg-blurple, bg-darker-bg, bg-dark-bg, text-discord-muted, text-discord-text, border-gray-600/700, accent-blurple) onto the existing --card / --primary / --text-muted / --background token system, and add light+dark semantic surface tokens for status colors so the Toast and strength meter render correctly in both themes.
