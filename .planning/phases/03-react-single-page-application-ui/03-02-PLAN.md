# Plan 03-02: Drive Shell, Listing, Breadcrumb, and File Type Icons

Build the three-region app shell, the breadcrumb navigation, the file/folder grid+list views, and the file-type icon helper. Includes TanStack Query hooks for folder listings.

## Traceability

- **Decisions Covered:** D-07, D-08, D-09, D-10, D-11, D-21, D-22
- **Requirements Covered:** UI-01, UI-02, UI-06

## must_haves

- [ ] `AppShell` renders top bar + left rail + main area, with the layout grid (60 px / 90 px / 1fr)
- [ ] `Breadcrumb` walks the parent chain and renders clickable segments
- [ ] `DrivePage` fetches `/api/fs/list?parent_id=...`, renders items as a grid by default, supports a grid/list toggle
- [ ] `FileCard` shows a file-type icon, name, and size
- [ ] `FileList` is a dense table view with the same data
- [ ] `getFileIcon` maps MIME types and extensions to the correct SVG sprite
- [ ] Selection store keeps the currently selected node id
- [ ] `useFolder` hook wraps TanStack Query and exposes `{ data, isLoading, error, refetch }`
- [ ] Unit tests for the icon helper, the breadcrumb, and the fs API client (mocked fetch)
