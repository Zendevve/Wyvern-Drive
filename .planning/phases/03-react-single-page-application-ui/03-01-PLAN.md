# Plan 03-01: SPA Scaffold, Auth Flow, and Design Tokens

Scaffold the Vite + React + TypeScript project under `web/`, install dependencies, set up the design-token CSS file, build the auth store + JWT helpers, and implement the `/` (auth/setup) page with a webhook URL input and connect button.

## Traceability

- **Decisions Covered:** D-01, D-02, D-03, D-04, D-05, D-06
- **Requirements Covered:** UI-01 (foundation), UI-05 (modal foundation)

## must_haves

- [ ] `web/` is a working Vite + React 18 + TypeScript project; `npm run dev` starts the dev server on port 5173 with a proxy to `http://localhost:3000` for `/api/*`
- [ ] `npm run build` produces a `dist/` bundle without errors
- [ ] `tokens.css` exposes all design tokens from the UI-SPEC
- [ ] `lib/crypto.ts` derives `accountId = SHA-256(webhookUrl).hex()` (matches server)
- [ ] `lib/storage.ts` reads/writes the JWT from `localStorage` under `wyvern.jwt`
- [ ] `lib/api.ts` exposes a typed `apiFetch` helper that attaches the bearer token and surfaces `Error` with status + body for non-2xx
- [ ] `store/auth.ts` (Zustand) holds `{ jwt, webhookUrl, accountId, status }` and exposes `login(webhookUrl)`, `logout()`, `restore()`
- [ ] `pages/AuthPage.tsx` shows the webhook URL form, posts `/auth/webhook`, stores the token, and navigates to `/drive`
- [ ] `App.tsx` routes between `/`, `/drive`, and `/drive/:folderId` (placeholder for now)
- [ ] Unit tests: `tests/lib/crypto.test.ts` (accountId derivation) and `tests/lib/storage.test.ts` (read/write/clear)
