# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (React/TSX vanilla CSS) |
| Icon library | custom SVG (defined in icons.tsx) |
| Font | Outfit (Google Fonts) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Sidebar padding, dashboard gap |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

---

## Typography

All text uses `-0.03em` letter-spacing on display/headings to match the Artano branding.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 500 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 700 | 1.2 |

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0D0E12 | Canvas base background, page body |
| Secondary (30%) | #16171F | Cards, Sidebar background, container cards |
| Accent (10%) | #FFFFFF | Glowing indicators, active text/border, logo mark |
| Destructive | #FF4D4D | Delete CTA and error alerts |

Accent reserved for: Active indicator bars, active state highlights, primary logo, and custom SVG storage arc glow.
