## Components

### Filter Chips (BROWSE-02)

Horizontal pill buttons for category filtering.

| State | Background | Text | Border | Icon |
|-------|------------|------|--------|------|
| Default | var(--bg-surface-2) | var(--text-secondary) | var(--border-subtle) | var(--text-secondary) |
| Hover | var(--bg-surface-1) | var(--text-primary) | var(--border-strong) | var(--text-primary) |
| Active | var(--accent) | var(--bg-base) | var(--accent) | var(--bg-base) |
| Disabled | var(--bg-surface-2) | var(--text-muted) | var(--border-subtle) | var(--text-muted) |

- Height: 32px
- Padding: 0 12px (horizontal), 6px 12px (with icon)
- Border radius: 999px (full pill)
- Gap: 8px between chips
- Count badge: 10px height, var(--bg-base) bg, var(--text-primary) text, 999px radius
- Animation: 200ms ease-out for all transitions
- Stagger: 50ms delay per chip on mount

### Folder Card Enhancements (BROWSE-03)

#### Favorite Star
- Position: Top-right of card, 8px from edges
- Size: 18x18px
- Default: Outline star (stroke only, var(--text-secondary))
- Hover: Filled white (var(--accent)), scale 1.1
- Active: Filled white, scale 1.0
- Animation: 150ms ease-out scale

#### Avatar Pile Mockup
- Position: Bottom-left of card, 8px from edges
- 3 overlapping circles (24px diameter each)
- Overlap: -8px margin-right
- Circle 1-2: var(--border-strong) border, var(--bg-surface-2) bg, initials in var(--text-secondary)
- Circle 3 (if >2): var(--accent) border, var(--bg-base) bg, "+N" in var(--text-primary)
- Z-index: incrementing (last on top)
- Transition: 200ms ease-out on hover (fan out slightly)

### Create Folder Card (BROWSE-04)

- Grid: 180px min-width, same height as file cards
- Border: 2px dashed var(--border-subtle)
- Border radius: var(--r-lg) (12px)
- Content: Centered vertically/horizontally
  - Plus icon: 32x32px, var(--text-muted)
  - Label: "New Folder", 13px, var(--text-secondary), font-weight 500
- Hover: Border → var(--accent), icon/label → var(--text-primary), bg → var(--bg-surface-2)
- Focus: Outline 2px var(--accent), offset 2px
- List view: First row, folder icon + "New Folder" name, same interactions

### Detail Panel Enhancements (DETAIL-01, DETAIL-03)

#### Collapsible Behavior
- Toggle button in topbar: Chevron left (expanded) / Chevron right (collapsed)
- Button: 32x32px, var(--bg-surface-2) bg, var(--border-subtle) border
- Animation: Width 320px ↔ 0, 200ms var(--ease-out)
- Padding: animate 16px ↔ 0 simultaneously
- Persist: localStorage key `detail-pane-collapsed`

#### Visual Preview Area
- Container: 100% width, aspect-ratio 16/9 (video), 4/3 (images), auto (audio/documents)
- Background: var(--bg-base)
- Border radius: var(--r-md) (8px)
- Overflow: hidden

##### Image Preview
- `<img>`: object-fit: contain, max-height: 300px
- Click: Open lightbox (full-screen overlay with zoom/pan)
- Lightbox: var(--bg-base) bg, 90% viewport, ESC to close

##### Video Preview
- `<video controls>`: width 100%, poster from first frame if available
- Muted autoplay on hover (preview)

##### Audio Preview
- `<audio controls>`: width 100%
- CSS waveform: 32 bars, 4px width, var(--accent) color, animated height

##### Document Preview
- PDF: `<iframe src={cdnUrl}>` with fallback to icon
- Others: Large file-type icon (64px), metadata below

#### CDN Status Indicator
- Position: Top-right of preview area
- Size: 8px diameter circle
- Colors: Success (valid), Warning (expired), Danger (error)
- Tooltip on hover: "CDN URL valid/expired/error"
