<objective>
Three consistency passes to harden the dashboard visual system: (1) document and enforce a single border-radius scale, (2) document and enforce a single z-index scale, (3) replace every hardcoded Tailwind color literal and every neon outer-glow with a theme-token equivalent.

Purpose: Without documented scales, the codebase has accumulated rounded-lg / rounded-xl / rounded-2xl / rounded-3xl / rounded-full for similar surfaces, scattered z-10/z-40/z-50/z-[100] values, and raw color literals (text-emerald-500, text-rose-500, bg-amber-500, bg-blue-500/10, bg-purple-500/10) that bypass the token system. The neon `shadow-[0_0_8px_rgba(...)]` on status dots is the only outer-glow in the app and is banned by the design skill section 9.A.

Output: A tokens.ts module that names the SHAPE_SCALE / Z_INDEX / SEMANTIC_COLORS, with the existing components updated to use it and the neon glows replaced with tinted background + saturated border.

Scope guard: This phase does NOT touch icons (Phase 07 owns), does NOT touch motion/perf (Phase 08 owns), does NOT touch theme tokens themselves (Phase 06 owns), does NOT introduce new colors. It does NOT add marketing-page components (no bento, no hero, no marquee, no zigzag cap, no trusted-by wall, no eyebrow caps, no "premium consumer palette" check). It does NOT add new spacing scales.
</objective>

   ```ts
   // SHAPE_SCALE — single source of truth for border-radius classes.
   // Use SHAPE_SCALE.input for form inputs and small buttons.
   // Use SHAPE_SCALE.card for cards, modals, panels, large surfaces.
   // Use SHAPE_SCALE.pill for chips, badges, status dots, and round buttons.
   export const SHAPE_SCALE = {
     input: 'rounded-lg',
     card: 'rounded-xl',
     pill: 'rounded-full',
   } as const;

   // Z_INDEX — single source of truth for stacking-context classes.
   // Use these instead of arbitrary z-[N] values.
   export const Z_INDEX = {
     base: 'z-0',
     raised: 'z-10',
     dropdown: 'z-20',
     sticky: 'z-30',
     overlay: 'z-40',
     modal: 'z-50',
     toast: 'z-[60]',
     skipLink: 'z-[100]',
   } as const;

   // SEMANTIC_COLORS — Tailwind class strings for status states.
   // All values resolve to a declared @theme token from src/index.css.
   export const SEMANTIC_COLORS = {
     success: { bg: 'bg-success', text: 'text-success', soft: 'bg-surface-success' },
     error: { bg: 'bg-destructive', text: 'text-destructive', soft: 'bg-surface-error' },
     warning: { bg: 'bg-warning', text: 'text-warning', soft: 'bg-surface-warning' },
     info: { bg: 'bg-primary', text: 'text-primary', soft: 'bg-primary/10' },

   ```
