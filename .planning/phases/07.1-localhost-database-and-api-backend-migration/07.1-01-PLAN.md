# Phase 07.1 Plan 01: Localhost database and API backend migration

## Objective

- **What:** Build a new TypeScript Express server with a local SQLite database that replicates the authentication, profile, file management, and share streaming endpoints of the Supabase backend. Integrate a mock adapter in the frontend so that the client talks to this local backend.
- **Why:** To make the application 100% cloud-independent, running self-contained on localhost.
- **Output:** A running `wyvern-backend` package, automated setup, and a modified web client with a custom, accessible auth form.
