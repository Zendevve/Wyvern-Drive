<objective>
Three performance and motion hygiene fixes for the dashboard: (1) viewport stability via 100dvh, (2) motion gating under prefers-reduced-motion, (3) transition-all hygiene, and (4) asset perf via self-hosted fonts and explicit image dimensions.

Purpose: The audit found h-screen (mobile viewport jump risk), unconstrained infinite animations (a11y regression under prefers-reduced-motion), render-blocking @import of fonts, and <img> tags without width/height/decoding (CLS + LCP risk). Even at MOTION_INTENSITY 3, infinite loops and bounces must collapse when the user requests reduced motion. Self-hosting fonts removes a third-party request from the critical path.

Output: A useReducedMotion hook, a prefers-reduced-motion CSS gate, 100dvh app shell, locally hosted woff2 fonts, preload links, transition-all hygiene pass, and audited <img> tags.

Scope guard: This phase does NOT touch icons (Phase 07 owns), does NOT touch theme tokens (Phase 06 owns), does NOT touch shape scale or z-index (Phase 09 owns). It does NOT add marketing-page motion (no hero parallax, no scroll-cue animation, no bento-card stagger). It does NOT remove decorative animations from non-loop sources (transitions on hover/state changes stay — only INFINITE animations and BOUNCES are gated).
</objective>
