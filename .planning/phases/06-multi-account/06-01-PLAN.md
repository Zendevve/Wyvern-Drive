# Phase 6: Multi-Account Support

**Goal**: A user can connect multiple Discord accounts, switch between them, and have per-account storage, dedup, and crypto state.

**Depends on**: Phase 5
**Requirements**: AUTH-04
**Status**: Pending
**Plans**: 1

## Context

Multi-account is the "one user, many Discord accounts" model. The use case: a user with a free Discord account for personal use and a Nitro account for large files, or several accounts to spread storage. **Not** the "many users, one drive" model — that's v3.

The Phase 2 server already supports multiple accounts per user; Phase 5 already supports per-account crypto. This phase wires the UI and verifies the boundaries.

## Plan 06-01: Multi-account store, account CRUD UI, per-account crypto/key isolation

**Tasks**:
1. **Account picker** (`<AccountSwitcher>`) in the top nav: shows current account avatar + username, dropdown to switch.
2. **Add account flow**: "Add Discord account" → opens a `<Dialog>` with token paste → validate → store.
3. **Remove account flow**: in account settings, "Remove this account" → confirm → DELETE `/accounts/:id` → server removes account + chunks refCounts (or marks as orphan).
4. **Active account state**: `useAuthStore.activeAccountId` is the source of truth. All API calls include it (cookie carries userId, header `x-account-id` carries the active account).
5. **File tree scoping**: switching accounts re-fetches the file tree for the new account.
6. **Per-account crypto state**:
   - Salt stored per-account.
   - On switching to an account, prompt for passphrase (if E2E enabled on that account).
   - Wrong passphrase → tree loads in "locked" state (metadata only, no file content).
7. **Per-account dedup verification**: integration test in server. Two accounts upload the same file → two distinct sets of Discord messages (no cross-account sharing).
8. **UI states**:
   - Locked account (E2E, no passphrase): show "Locked" badge, hide file content but show metadata.
   - Switching: clear crypto state of the previous account.

**Acceptance**:
- User can add a second Discord account, switch between them, and see distinct file trees.
- Per-account dedup: integration test confirms no cross-account message sharing.
- Per-account crypto: switching to a locked E2E account requires passphrase re-entry.
- Removing an account revokes its JWT and removes the local session for that account.
