# @disbox/ext

MV3 Chrome extension for Disbox v2. Filled in during **Phase 4**.

The extension is a **convenience** that detects `discord.com/channels/...` links on the web and offers to open them in the Disbox web app. It is **not** load-bearing — the web app works fully without the extension installed (unlike v1, which needed the extension to bypass Discord CDN CORS).
